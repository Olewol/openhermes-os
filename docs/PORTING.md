# Porteringskart: OpenClaw OS → Hermes Agent

Status 24.11.2026, branch `hermes-native` @ `7661886`+. Hermes 0.23.2 (tree `776e4897fa`; stier under «Hermes» er relative til `~/.hermes/hermes-agent`). Alt er lest i kode; det som er kjørt mot ekte Hermes står i [HERMES.md](./HERMES.md). Ingenting her er bygget i fase 1b.

**Les slik:** *Fra* = OpenClaw-funksjonen (fil:linje i denne repoen). *Hermes* = nærmeste mekanisme (fil:linje i Hermes). *Status* = `virker` (kjørt) / `kode` (skrevet, ikke kjørt) / `stub` / `mangler`. *Str.* = S (< 1 dag), M (1–3 dager), L (> 3 dager); **vurdering**, ikke målt.

## Hovedkonklusjon

OpenClaw OS er to deler: en **klient** (`packages/claw-client`) og en **server-plugin** (`packages/claw-plugin`, 2 693 linjer TypeScript). Klienten er portert for chat (fase 1). Alt som bor i pluginen (apps, artefakter, varsler, opplasting, `tools.invoke`, OpenUI-prompten, SQLite-verktøyene) har **ingen motsvarighet** i Hermes' gateway og må bygges som en **Hermes-plugin** (Python). Hermes har plugin-flaten som trengs: `register_tool`, `register_hook` (`pre_llm_call`), `register_command`, `register_skill`, dashboard-manifest med eget `api` (se §4).
